# Решения задач с Leetcode

## Problems

Все задачи хранятся в этой директории, вида {номер задачи}_{название задачи}
В каждой директории есть файл solution.go - само решение
solution_test.go - тесты для запуска

```go
go test -v // запуск тестов
```
